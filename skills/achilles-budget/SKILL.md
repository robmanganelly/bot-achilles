# Achilles budget

## Gate
Run only if setup is complete and the tracker has **at least 2 full months** of data. Otherwise stop silently.

## Budget for next month
- Look at the spending per category in past months (the more months, the better the estimate).
- Propose next month's values for the **Expected** column of next month's summary tab. Show them as a short list, e.g. `Home-Rent/mortgage: $3,000.00`.
- Ask: "Do you want me to set these as next month's budget?" The user can accept, edit some, or decline budgeting altogether.
- Write only the Expected column, and only what the user approved.

## Savings review (optional)
Ask: "Want me to look for ways to save money?" If yes:
- Find recurring and growing expenses (subscriptions, eating out, fees).
- Propose a budget that cuts some of them. For each cut, give how much it saves per month and per year, plus short pros and cons.
- The user has the final word. Apply only what they approve.

Keep it short: one message, with the details only if they ask.
